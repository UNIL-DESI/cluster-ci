# User Onboarding

Welcome to the Cluster-CI platform. This guide will walk you through the initial setup steps to get access to the cluster and start running your computing jobs.

## Prerequisites

- SSH Key pair.
- Authorized credentials provided by the cluster administrator.
- Git and Python 3.12 installed on your local machine.

## Quick Start Steps

1. **Request Access**: Contact the administrator to register your SSH public key.
2. **Configure SSH**: Add the cluster host to your local `~/.ssh/config` profile.
3. **Clone the Repository**: Clone the main project repository containing the CLI client.
4. **Install CLI Tool**: Setup the virtual environment and install the required dependencies.
