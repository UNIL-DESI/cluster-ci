# Support & Contributions

If you run into issues or want to contribute new improvements to the Cluster-CI platform, please use the guidelines below.

## Reporting Issues

1. **Check Logs**: Retrieve execution logs using `cluster-run view <run_id>`.
2. **Search Issues**: Check existing issues on GitHub to see if your bug has been reported.
3. **Submit Ticket**: Open a new issue with a clear description, reproduction steps, and log output.

## Contributing

- **Atomic Commits**: Ensure commits are atomic and have clear messages.
- **Documentation**: If modifying a feature, update the corresponding documentation.
- **Tests**: Write and run tests before requesting a code review.
