# Cluster-CI Documentation

Welcome to the official documentation for **Cluster-CI**, a GPU-accelerated computing cluster based on NVIDIA Blackwell GB10 GPUs with 128GB of RAM running on Ubuntu 24.04.

This platform provides researchers and developers with high-performance resources for deep learning, AI inference, and scientific computing.

## Document Structure

- **User Guides**: Intended for researchers and cluster users. Learn how to get onboarded, use the command-line interface, manage DVC data/storage, submit jobs to the CI/Queue Scheduler, monitor workloads, and get support.
- **Developer Docs**: Intended for platform developers and maintainers. Covers the cluster architecture, dashboard internals, preflight scans, scheduler implementation, security protocols, and vLLM integration.

Get started by reading the [Onboarding Guide](user/onboarding.md).
